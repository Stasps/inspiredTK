## agent-tasks

### MVP-0. Прототип
Цель: проверить ядро цикла "стройка - производство - война" на минимальном наборе. Системы и числа - разделы с тегом MVP-0 в [[game-design]].

- [ ] Проектный каркас и слой данных: конфиги (ресурсы, здания, юнит, бой), валидация конфигов при старте
- [ ] Карта 100x100: генерация месторождений, размещение стартовой деревни игрока
- [ ] Деревня: 6 зданий, 4 ресурса, производство по серверному времени
- [ ] Войска: пехотинец, марши, провиант, отмена марша
- [ ] Бой: формула атака/защита, модификаторы 1.5/3.0, потери
- [ ] PvE: 5-10 статичных лагерей варваров, атака раз в 24 часа в окна игрока
- [ ] Тестовый режим "завершить немедленно"
- [ ] Сохранение состояния: периодические JSON-снапшоты по [[save-structure]] (состояние только в памяти запрещено - см. [[architecture]]; PostgreSQL - позже, при первом прототипе нагрузки)
- [ ] Headless-тесты логики (бой, производство, марши)

### MVP-1. Ядро
Цель: полный игровой цикл сетевой игры. Системы и числа - разделы с тегом MVP-1 в [[game-design]].

- [ ] Ресурсы: 6 базовых + 3 составных, T2-цепочки (сталь, оружие, доспехи)
- [ ] Здания: 13 типов
- [ ] Юниты: 6 типов; герой (опыт, уровни)
- [ ] Экономика: NPC-бартер с плавающим курсом
- [ ] PvE: 20-30 растущих NPC-деревень, захват с наградой-землёй
- [ ] Склады: две категории (продовольственный/непродовольственный), гниение при переполнении
- [ ] Удержание: ежедневные квесты, серия входов, карта событий (караваны, руины)
