# О чем документ
Здесь прописан арт-дирекшен, которому нужно следовать при генерации арта для игры.
Арт-дирекшен при явных правках можно дополнять и уточнять.

## Стиль

- 2D, простая графика [Зафиксировано]
- Два режима отображения: красочная / производительная [Зафиксировано]
- Детали стиля не зафиксированы - раздел ждёт наполнения от человека

## Референсы

| Игра                 | Оценка                | Что рефаем / не рефаем                                                                |
| -------------------- | --------------------- | ------------------------------------------------------------------------------------- |
| **Travian Kingdoms** | Механический референс | Читаемость карты и UI браузерной стратегии. Не рефаем устаревший визуал               |
| Lords Mobile         | игровая механика      | Идея с rally - сбор всех войск королевства (несколько игроков) для одной мощной атаки |
