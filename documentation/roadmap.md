## agent-tasks

### MVP-0. Прототип
Цель: проверить ядро цикла "стройка - производство - война" на минимальном наборе. Системы и числа - разделы с тегом MVP-0 в [[game-design]].

- [x] Проектный каркас и слой данных: конфиги (ресурсы, здания, юнит, бой), валидация конфигов при старте
- [x] Карта 100x100: генерация месторождений, размещение стартовой деревни игрока
- [x] Деревня: 6 зданий, 4 ресурса, производство по серверному времени
- [x] Войска: пехотинец, марши, провиант, отмена марша
- [x] Бой: формула атака/защита, модификаторы 1.5/3.0, потери
- [x] PvE: 5-10 статичных лагерей варваров, атака раз в 24 часа в окна игрока
- [x] Тестовый режим "завершить немедленно"
- [x] Сохранение состояния: периодические JSON-снапшоты по [[save-structure]] (состояние только в памяти запрещено - см. [[architecture]]; PostgreSQL - позже, при первом прототипе нагрузки)
- [x] Headless-тесты логики (бой, производство, марши)
- [x] WebSocket транспорт (localhost:8080)
- [x] Debug HTML клиент для тестирования
- [x] Реальные команды: строительство, тренировка, чит-код, карта
- [ ] Исправить `TrainUnits` для поддержки разных типов юнитов (сейчас хардкод infantry)


**Архитектурные решения MVP-0 (зафиксировано):**
- Обработка команд: A1 — main.go select (один цикл, нет race condition)
- Результат клиенту: B1 — broadcast всем (1-10 игроков, нагрузки нет)
- Очередь команд: C2 — FIFO (первый пришёл — первый ушёл)
- Переполнение очереди: D1 — отклонять с ошибкой (просто, прозрачно)

### MVP-1. Ядро
Цель: полный игровой цикл сетевой игры. Системы и числа - разделы с тегом MVP-1 в [[game-design]].

- [ ] Ресурсы: 6 базовых + 3 составных, T2-цепочки (сталь, оружие, доспехи)
- [ ] Здания: 13 типов
- [ ] Юниты: 6 типов; герой (опыт, уровни)
- [ ] Экономика: NPC-бартер с плавающим курсом
- [ ] PvE: 20-30 растущих NPC-деревень, захват с наградой-землёй
- [ ] Склады: две категории (продовольственный/непродовольственный), гниение при переполнении
- [ ] Удержание: ежедневные квесты, серия входов, карта событий (караваны, руины)

**Архитектурные решения MVP-1 (план):**
- Результат клиенту: гибрид — приватные команды + публичные события (100-500 игроков)
