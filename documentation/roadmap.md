## agent-tasks

### MVP-0. Прототип
Цель: проверить ядро цикла "стройка - производство - война".

**Сервер:**
- [x] Проектный каркас: конфиги, валидация, слои (Data/Logic/Storage)
- [x] Карта 100×100: генерация месторождений, лагерей варваров
- [x] Деревня: 6 зданий, 4 ресурса, ленивое производство
- [ ] Добавить здание "Склад"
- [x] Войска: пехотинец, марши, провиант
- [x] Бой: формула атака/защита, модификаторы 1.5/3.0
- [x] PvE: 5-10 лагерей варваров, атака раз в 24 часа
- [x] Сохранение: JSON-снапшоты + журнал событий
- [x] Тесты логики
- [x] Система координат -50..50, центр (0,0)
- [ ] Статический файловый сервер в Go (убрать file:///, открывать через http://localhost:8080/)
- [ ] Rate limiting для WebSocket (защита от флода)

**Клиент:**
- [ ] SPA-архитектура: одна страница, роутинг через hash, общий WebSocket, переключение панелей без перезагрузки
- [x] WebSocket-подключение, команды, отображение ошибок
- [x] Интерфейс: ресурсы, здания, армия, прогресс-бары
- [x] Debug-панель: finish_now, add_resources, skip_time
- [x] Карта: отображение, закрытие
- [x] Цветовые темы (3 шт.), эмодзи
- [x] Производство в час в шапке
- [ ] Стоимость тренировки в интерфейсе

**Архитектура:**
- [ ] Продумать масштабирование broadcast при росте онлайна (>10 игроков)
- Обработка команд: main.go select (один цикл)
- Рассылка состояния: broadcast всем подключённым (до 10 игроков, для MVP-0 достаточно)
- Очередь команд: FIFO, буфер 100
- Переполнение: отклонять с ошибкой
- Время: событийно-ориентированная модель (Compute on Read + планировщик)

**Отложено в рамках MVP-0:**
- [ ] Атака через выбор клетки на карте
- [ ] Склад и амбар: вместимость, отображение
- [ ] ID игрока в логах подключения
- [ ] TrainUnits: поддержка разных типов юнитов

### MVP-1. Ядро
Цель: полный игровой цикл сетевой игры. Системы и числа - разделы с тегом MVP-1 в [[game-design]].

- [ ] Ресурсы: 6 базовых + 3 составных, T2-цепочки (сталь, оружие, доспехи)
- [ ] Здания: 13 типов
- [ ] Юниты: 6 типов; герой (опыт, уровни)
- [ ] Экономика: NPC-бартер с плавающим курсом
- [ ] PvE: 20-30 растущих NPC-деревень, захват с наградой-землёй
- [ ] Склады: две категории (продовольственный/непродовольственный), гниение при переполнении
- [ ] Удержание: ежедневные квесты, серия входов, карта событий (караваны, руины)
- [ ] Кнопка "+n пехотинцев" (вместо фиксированных +1/+10)
- [ ] Осадные единицы: аналог катапульты+тарана, разрушают защитные сооружения
- [ ] Появление игроков по спирали от центра
- [ ] Боты, эмулирующие игру человека (упрощённо)
- [ ] Кнопка "+n пехотинцев" (вместо фиксированных +1/+10)

**Архитектурные решения MVP-1 (план):**
- Результат клиенту: гибрид — приватные команды + публичные события (100-500 игроков)
