# О чем документ
Здесь лежат атрибуты качества к разным видам дизайна и системам.
Нейронка пишет сюда новые атрибуты качества, которые человек выдаёт ей в виде правок.

## server
- **Никаких дюпов**: начисление и списание ресурсов только на сервере, атомарно в одном расчёте по прошедшему серверному времени (лениво, по формуле - не циклом по тикам). Проверяется тестами на граничных случаях (переполнение склада, отмена марша, одновременные траты)
- **Честный бой**: расчёт боя только на сервере; результат воспроизводим из входных данных марша
- **Один источник времени**: сервер (см. [[game-design]], "Серверное время"); клиентские таймеры никогда не влияют на логику
- **Оффлайн-прогресс по формуле**: состояние считается по прошедшему времени, а не симуляцией каждого игрока каждый тик; сервер выдерживает целевой онлайн (1000-15000, см. [[concept-doc]])
